Live PoC - cross-origin postMessage DOM-XSS on corporates.db.com

This page is served from a foreign origin (GitHub Pages). It frames a real Deutsche Bank Livebook flipbook and delivers a crafted book.xml via postMessage. The flipbook's window.onmessage has no origin check, so the XML's <node title> is rendered through jQuery .append() unescaped, and script executes in the corporates.db.com origin.
